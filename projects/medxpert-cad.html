The clinical workflow

01

One interface routes imaging questions to specialized clinical tools.

MedXpert-CAD coordinates chest X-ray analysis, lumbar MRI assessment, external medical search, and evidence-based response generation through standardized MCP tool interfaces.

Agent architecture

Four agents.
Three MCP servers.

The published system separates supervision, evidence retrieval, X-ray analysis, and lumbar spine MRI assessment.

01

Supervisor agent

Interprets the request and routes it to the appropriate modality-specific tool or search workflow.

02

Deep search agent

Retrieves supporting evidence from PubMed, Google Search, and vector or graph knowledge sources.

03

X-ray expert

Supports multi-label classification, saliency-based localization, visual question answering, and structured reporting.

04

LSS expert

Processes lumbar MRI and DICOM data for segmentation, measurements, stenosis analysis, and structured reporting.

Research scope

02

Current scope and limitations.

The reported system focuses on static chest X-ray and lumbar MRI workflows. The paper notes that broader multi-institutional validation is still needed and that dynamic modalities such as ultrasound are outside the current scope.
